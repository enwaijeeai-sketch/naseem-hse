# Naseem.HSE

نظام إلكتروني لإدارة تحديد وتحليل وتقييم المخاطر المهنية (HERA).

## الشركة

شركة النسيم للصناعات الغذائية  
Naseem Food Industries

## الهدف

يهدف التطبيق إلى إدارة نماذج HERA للمعدات والآلات والعمليات الفنية، وإنشاء سجل مركزي للمخاطر، ودعم تقييم المخاطر باستخدام مصفوفة 5×5.

## الخصائص المستهدفة

- واجهة عربية مع مصطلحات إنجليزية واتجاه من اليمين إلى اليسار
- يعمل على الهاتف والكمبيوتر
- نماذج HERA 1 وHERA 2 وسجل HERA المركزي
- حساب درجة الخطر: الاحتمال × الشدة
- العمل دون إنترنت والمزامنة عند توفر الإنترنت
- صلاحيات للفني والمشرف ومسؤول HSE ومدير النظام
- مرفقات: صور، PDF، توقيع، موقع جغرافي وملاحظات صوتية
- تقارير Excel وPDF ولوحة مؤشرات
